# Bug Report for Failing Tests

Create GitHub issues for failing tests, avoiding duplicates.

## Process

For each failing test identified in the conversation or from running tests:

### 1. Check if issue already exists

```bash
gh issue list --search "bug: {TestName} in:title" --state all --json number,title,state --limit 5
```

If an issue exists (open or closed), report it and skip to the next test.

### 2. Create new issue if not exists

```bash
gh issue create \
  --title "bug: {TestName}" \
  --assignee "@copilot" \
  --body "## Failing Test

**Test:** \`{FullyQualifiedTestName}\`

## Error

\`\`\`
{ErrorMessage}
\`\`\`

## Stack Trace

\`\`\`
{StackTrace}
\`\`\`

## Context

{WhatTheTestValidatesAndPossibleRootCause}

## Suggested Investigation

{AreasToInvestigate}

---
*Auto-generated by /bugreport*"
```

### 3. Summary

Report:
- Issues created (with links)
- Issues that already existed
- Total tests processed
