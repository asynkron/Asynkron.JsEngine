Compiler Frontend

JsLexer and JsAstParser are a real compiler frontend. They produce typed immutable AST nodes with source spans, not direct runtime behavior.

Two Execution Worlds

The intended fast path is AST -> cached analysis -> IR -> ExecutionPlanRunner. The AST evaluator remains for dynamic JavaScript semantics and unsupported IR shapes.

Host Boundary

The Node-style demos sit outside the engine core. They exercise HostFunction, module loading and async scheduling while JavaScript semantics stay in the runtime.
