Pipeline

  • * `JsEngine.Parse` creates `Lexer`, tokenizes source, then feeds `Parser`.
  • * `Parser.ParseProgram` emits a `Cons` tree tagged by shared `JsSymbols`.
  • * `JsEngine.Evaluate` delegates the tree to `Evaluator.EvaluateProgram`.

Runtime Model

  • * Execution is a direct S-expression tree walk returning `object?` values.
  • * `Environment` stores symbol bindings and models lexical nesting.
  • * `Return`, `throw`, `break`, and `continue` use dedicated C# signal exceptions.

Object Model

  • * `JsObject` is a dictionary with `__proto__` traversal.
  • * `JsArray` wraps indexed storage plus object-like properties.
  • * `JsFunction` captures closure environments; `HostFunction` bridges C# callbacks.
