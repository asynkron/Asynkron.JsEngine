# Bytecode Grammar Coverage Appendix

This appendix maps grammar shapes that were flagged as having no dedicated
decline leaf to the primitive that currently owns them. A row marked
`covered by primitive` should not become a new decline code unless the cited
primitive stops owning that shape. A row marked `real gap` still needs a named
lowering or decline owner before the burn-down list can call the grammar surface
finite.

## Coverage Map

## Follow-Up Rules

- Do not create a decline family solely because a grammar construct has no enum
  row. First identify the primitive it lowers into and add the proof anchor to
  this appendix.
- If a construct has no AST/lowering owner (`debugger;` today), add that owner
  before claiming the grammar census is closed.
- If a construct lowers into synthetic statements, preserve completion-value and
  lexical-environment semantics in the lowering owner instead of adding runner
  fallback behavior.
